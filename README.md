# Invent X Solutions: sitio web

Página web de **Invent X Solutions**, un emprendimiento de desarrollo de software que ofrece alojamiento web, implementación de software y automatización a empresas.

## Autor

**Juan Esteban Ossa**, estudiante de Negocios Internacionales.

## Contexto del proyecto

Este proyecto parte de un emprendimiento real llamado Invent X Solutions, al cual se le realizó una **transformación digital**. Como parte de ese proceso se creó este sitio web, que le da al negocio presencia en línea y un canal de contacto directo con sus clientes por WhatsApp.

## Servicios que presenta el sitio

- **Alojamiento web:** sitio o tienda en línea con seguridad, copias de seguridad, correos corporativos y soporte.
- **Implementación de software:** instalación o desarrollo a la medida del software que la empresa necesita, con capacitación y mantenimiento.
- **Automatización:** procesos repetitivos como facturas, reportes, avisos y sincronización de datos entre sistemas.

## Características

- Página de una sola vista, en un único archivo HTML.
- Sin backend: no necesita servidor, base de datos ni formularios.
- Logo incrustado en el mismo archivo.
- Botón flotante de WhatsApp y un enlace de cotización por cada servicio, con el mensaje ya escrito.
- Diseño adaptable a computador, tablet y celular.
- Respeta la preferencia de movimiento reducido del dispositivo.

## Estructura

```
index.html   Página completa (HTML, CSS y logo incrustados)
README.md    Este archivo
```

## Cómo usarlo

1. Descarga el archivo `index.html`.
2. Ábrelo con doble clic en cualquier navegador.
3. Para publicarlo, súbelo a un hosting o a un servicio de páginas estáticas.

## Cómo personalizarlo

- **Número de WhatsApp:** busca `573052231460` en `index.html` y reemplázalo en todos los enlaces. El `57` es el código de Colombia.
- **Textos de los servicios:** están dentro de la sección con `id="servicios"`.
- **Colores:** se definen como variables al inicio del bloque `<style>`, en `:root`.

## Tecnologías

- HTML5 y CSS3.
- Fuente Outfit de Google Fonts (necesita internet; si no carga, el navegador usa una fuente del sistema).
- No usa JavaScript ni frameworks.
